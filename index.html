KPIs

Worked out every month from your full audits (by discharge month). Each KPI can be edited.

VTE KPI · BH-MSA-KPI-127 (from the hospital Grid, ICD codes)

Incident of hospital-associated VTE. (Adult discharges with LOS ≥ 2 days and VTE as a secondary diagnosis + emergency readmissions within 90 days with VTE as the principal diagnosis) ÷ adult discharges with LOS ≥ 2 days × 1000. Target 0 · Trigger 0.5% (= 5 per 1000).

Load this month's files

Each month load the VTE visits file (like VTE_Oct2026.xlsx): every VTE visit is checked and you see whether the month is 0. For the denominator, load the full Grid (all inpatient discharges) if you have it, or type the number in the table below. Files can be added again: visits already loaded are updated, not counted twice. Names, phone and ID numbers are not kept. Nothing leaves this browser.

You can choose several files at once. For B (readmissions) to be final, the next 3 months' VTE files are needed too (90-day window); until then the month shows "B provisional".

How it is counted

  • VTE codes: I26 (PE), I80.2 / I80.3 (DVT), I82 (other venous thrombosis). Z86.7 (history) is not counted.
  • Principal vs secondary: the Grid has no diagnosis-type column, so the first code in the Diagnosis cell is taken as principal and the rest as secondary. Confirm with Coding if the order is not reliable.
  • Denominator: IP visits discharged in the month, age ≥ 18, LOS (discharge date − admission date) ≥ 2 days.
  • Numerator A: a denominator discharge with a VTE code that is not the first code.
  • Numerator B: a denominator discharge followed by another IP admission of the same file within 90 days whose first code is VTE (and, when the option is on, with an ER visit that day or the day before). Each discharge counts once.
  • The Grid has no admission-type field, so "emergency" is estimated from the ER visit. A month stays provisional until the data covers 90 days after it.
