How a file moves

      

    

    

      
First time setup
    
        
  1. Data → Import Excel audit. Loads your past audits, emails sent and statuses, so the dashboard starts with your history.
    2. 
        
  2. Data → Import contacts. Loads doctor emails.
    3. 
        
  3. Doctors → Confirm all strong matches, then review the rows marked Check or No match and pick the right contact. Done once; new doctors appear here as they are audited.
    4. 
        
  4. Data → Download backup file. Repeat weekly.
    5. 
      

      
Every day
    
        
  1. Data → Import files to audit loads the list of discharged files not audited yet. They wait on the Audit tab with file number, dates, LOS, department and doctor ready.
    2. 
        
  2. Quick audit (Audit tab → Quick audit): for files checked only for completion. Press ✓ Complete or ✗ Not complete. Not complete goes to Stalled files with the same emails and reminders.
    3. 
        
  3. Audit tab: press Audit on a file in the worklist (or type a file number). Press "Set all to ✓", then click the boxes that are NA or deficient (✗). Save.
    4. 
        
  4. Stalled files tab opens on what needs action today. Press Send 1st email: Outlook opens with the message ready, and the date is recorded. If Outlook did not open, press Undo.
    5. 
        
  5. After 3 days the file appears under 2nd reminder due. Press Send 2nd reminder.
    6. 
        
  6. When the doctor completes the documentation, press Completed. The file leaves the list and counts as closed after email.
    7. 
        
  7. Files not completed 7 days after the 1st email turn Delinquent (red).
    8. 
      

    

    
Quarterly report
    
      
  1. Dashboard → Period → choose the quarter (for example Q3 2026).
    2. 
      
  2. Filter by department or doctor if needed.
    3. 
      
  3. "Copy report summary" gives the key figures as text. "Export to Excel" saves every table for the report.
    4.
